# piskvorky-5x5

Five-in-a-row game on a 15×15 board — play vs. computer or a friend.

## Run

Requires Python 3.

```bash
python piskvorky5x5.py
```

## Notes

- Computer move scores open and closed runs in all four directions
- Highlights the winning row and the last move
